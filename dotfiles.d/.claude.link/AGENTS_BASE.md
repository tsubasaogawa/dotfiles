# AGENTS.md - BASE

## 表現

- 日本語テキストと英単語・数字の間には必ず半角スペースを入れる
  - 正: "GitHub リポジトリ 1"
  - 誤: "GitHubリポジトリ1"
- 全角カッコ（）は使用禁止。半角 `()` を使い、半角スペースはカッコの外側のみに入れる (内側には入れない)
  - 正: `理解 (Terraform) に誤りはない`
  - 誤: `理解（Terraform）に誤りはない`、`理解 ( Terraform ) に誤りはない`
- 強調 (`**...**`) とインラインコード (`` `...` ``) は本当に必要な箇所だけに使う
  - ただしコードブロック ``` は例外
- 英単語を区切る際は半角カンマ
  - 正: First, second, third
  - 誤: First、second、third
- 基本的に絵文字は利用しない
- 英単語はそのまま使うのではなく、自然なカタカナ語・和語に寄せる
  - 例: `path` → パス、`rule` → ルール
  - 固有名詞・AWS リソース名・サービス名・略称 (ALB, ECS など) はそのまま英語表記で良い
